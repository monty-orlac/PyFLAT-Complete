# 2次元有限要素法プログラム PyFLAT Complete version

*A 2D simple structural analysis solver using the Finite Element Method for educational purposes.*

## はじめに
**PyFLAT** (=Python program for Finite-element Linear Analysis Tutorial) complete version は Python で記述された有限要素法プログラムで、2次元の線形静解析に対応しています。

## 動作環境
PyFLAT の実行には、下記の環境およびパッケージが必要です。
- Python: 3.12 以降
- NumPy: 2.0 以降
- SciPy: 1.13 以降
- Numba: 0.59 以降

上記のパッケージはいずれも必須です。プログラム開始時にインストール状況とバージョンを確認し、条件を満たさない場合はメッセージを表示して終了します。パッケージは、例えば pip を使って下記のようにインストールできます。
```batch
  > pip install numpy scipy numba
```

## プログラムの実行とコマンドラインオプション
PyFLAT は解析モデルを定義した入力ファイル1つと任意個のオプション引数を取ることができます。そのため、コマンドライン上で下記の指定を行うことで入力ファイル (下記の場合は `sample.in`) を実行できます。
```batch
  > PyFLAT [options] sample.in
```
なお、 PyFLAT は Python プログラムなので、本来の実行コマンドは `PyFLAT ...` ではなく、リポジトリ直下から実行する場合は `python src/pyflat.py ...` といった形になりますが、ここでは簡単のため、`PyFLAT` というエイリアス名でプログラムが実行できると仮定しています。

使用できるオプション引数の一覧は `-h` もしくは `--help` 引数を与えることで確認できます。そのほかのオプション引数を下記に紹介します。(※)がついたものは表の下に補足説明を行っていますので、そちらも合わせてご参照ください。

| option     | description |
| :--------: | ----------- |
| `-h`, `--help`      | 実行コマンドに関するヘルプを表示して終了します。 |
| `-V`, `--version`   | \[\[デバッグ用オプション\]\] PyFLAT のバージョン番号を表示して終了します。 |
| `--cutoff TOL`      | 絶対値が基準に対する割合 `TOL` 以下となる微小な結果値をゼロに丸めます (※)。 |
| `--solver TYPE`     | 利用する線形代数ソルバーのタイプ `TYPE` を指定します (※)。 |
|  `-v, --verbose`    | デバッグのために途中状態をいくつか追加出力します。 |
| `--hourglass VALUE` | 低減積分要素のアワーグラス制御の強さを `VALUE` にします (※)。 |
| `--reorder METHOD`  | 節点の自由度割り振りアルゴリズムを `METHOD` にします (※)。 |
| `--debug`           | \[\[デバッグ用オプション\]\] プログラムがエラー終了したときにトレースバックを表示します。 |
| `--validate`        | \[\[デバッグ用オプション\]\] バージョン情報・ライセンス表示と実行時間の表示を省略して実行します。実行環境によって変わる情報が出力されないため、計算結果を過去の出力と比較する場合に使用します。 |

### 計算結果のカットオフ `--cutoff`
数値計算の結果は丸め誤差や情報落ちなどにより非常に小さな値が残ることがあります。これをカットオフにより強制的に `0.0` にしてしまうためのオプションです。ここで指定する値を `TOL` としたとき、これは下記のように働きます。

- 節点変位について、最大変位値 (すなわち行列ソルバーにより求解された変位ベクトルの成分の絶対値での最大値) に対し、絶対値が 最大変位量×`TOL` 以下の成分はゼロとなります。
- 要素応力について、各要素の各積分点における応力の大きさを基準とし、絶対値が 基準値×`TOL` 未満の成分をゼロとします。

なお、カットオフは純粋に表示だけに影響を及ぼすものです。例えば、要素応力の計算に使われる節点変位は、`--cutoff` 設定に関わらずカットオフ前の生の値が使われます。

デフォルト値は `1.0e-8` です。カットオフ処理を一切行わない場合は `--cutoff 0.0` を指定します。


### 線形代数ソルバーの指定 `--solver`
PyFLAT は利用する線形代数ソルバーを下記の中から選択することができます。
- `DENSE` ... SciPy を使った密行列の直接法ソルバー (Cholesky分解)
- `DIRECT` ... SciPy を使った疎行列の直接法ソルバー (LU分解) (デフォルト)
- `ITERATIVE` ... SciPy を使った疎行列の反復法ソルバー (不完全LU分解+共役勾配法)
- `SKYLINE` ... スカイライン格納形式の直接法ソルバー (修正Cholesky分解)

実用的なものは `DIRECT` か `ITERATIVE` であり、小規模な問題から大規模な問題まで、高い性能を発揮します。

`DENSE` は密行列を使った最も単純なソルバーで、計算効率の比較のための参考実装です。小規模な問題であれば問題なく使えますが、中規模以上の問題に対しては計算時間・メモリ使用量ともに大きくなり、`DIRECT` や `ITERATIVE` に対して性能が大幅に落ちます。

`SKYLINE` は有限要素法でよく紹介されるスカイライン法のソルバーで、外部ライブラリに頼らない実装です。JIT コンパイラの Numba により高速化されているため、中規模以上の問題でも実用的な速度で実行できます。ただし、`SKYLINE` を使う場合は、実行のたびに JIT コンパイルのため 1 秒程度の時間が追加でかかります。また、計算時間は節点の自由度割り振り (`--reorder`) の影響を大きく受けます。


### 節点の自由度割り振りアルゴリズムの指定 (--reorder)
節点が持っている自由度を全体剛性行列のどの行 (・列) に割り当てるかというアルゴリズムについて、PyFLATは下記の2種類を選択できます。
- `SIMPLE` ... 節点IDの小さい順に単純に自由度を割り当てる
- `RCM` ... RCM (Reverse Cuthill-McKee) 法相当の割り当てアルゴリズムを利用

デフォルトは `RCM` です。このアルゴリズムは疎行列の直接法を選択する場合 (すなわち `--solver` が `SKYLINE` か `DIRECT` の場合) のみで有効で、`DENSE` と `ITERATIVE` の場合は計算効率に影響しないため、本指定が無視され、常に `SIMPLE` が使用されます。LU分解 (Cholesky分解等派生アルゴリズムを含む) では「フィルイン」が発生しますが、そのフィルインを最小限にするには、バンド幅 (行列の非ゼロ成分の対角成分からの距離) を小さくする必要があります。RCM 法はそれを考慮するためのアルゴリズムであり、簡単ながら非常に効率よくフィルインを抑制できます。

RCM法では、要素を介した節点同士の接続関係 (全体剛性行列の非ゼロ要素のパターン) を利用します。ある始点となる節点から出発し、隣接する節点、さらにその先に接続する節点へと、網の目を辿るように順番に走査 (探索) していきます。この探索順に沿って自由度番号を再割り当てすることで、接続関係のある自由度同士の番号が近接するようになり、行列のバンド幅が縮小されます。

なお、`--solver DIRECT` の場合に内部で使用されるLU分解ソルバーの `scipy.sparse.linalg.splu()` では、自分自身が並べ替えアルゴリズムを数種類持っており、`permc_spec` オプションで切り替えることができます。ただし、ここでは `--reorder` のアルゴリズムによる計算効率の違いを体験するため、並べ替えを行わない `permc_spec="NATURAL"` を敢えて使用していることに注意が必要です。


### アワーグラス制御の強さ (--hourglass)
本プログラムで実装されている低減積分要素はgamma-projection法によるアワーグラス制御を行います。この手法は、要素が歪んだ場合でも剛体運動や一定歪み状態を正確に保持（パッチテストを満足）しながら、アワーグラス変形のみを抽出して抑制する高度な投影手法です。gamma-projection法では制御の強さを指定することが可能で、その値を `--hourglass` オプションにて与えることができます。

この値を大きくするほどアワーグラスモードを強く抑制できますが、過大に設定すると要素全体が本来よりも硬くなり (剛性の過大評価)、解析精度が低下します。デフォルト値は 0.01 に設定されており、本来の要素剛性を損なわずにアワーグラスを最小限に抑えるバランス型の設定です。変位分布にジグザグ状の模様 (アワーグラスモード) が現れる場合は 0.1 程度まで引き上げると良いです。

なお、`--hourglass 0.0` を指定するとアワーグラス制御が無効になります。この場合、全体剛性行列が特異となってエラー終了することが多いため、通常は `0.0` を指定しないでください。


## 入力ファイルの書式
本プログラムは、モデルと解析条件を入力ファイルで指定します（計算結果の出力については「[出力データ概観](#出力データ概観)」を参照してください）。

入力ファイルの例を下記に示します。
```
// ***************************************
//  Model definition
// ***************************************
NODE
  NODE,    1,    1,    1,    0.00000,    0.00000,
  NODE,    2,    0,    0,    1.00000,    1.60000,
  NODE,    3,    0,    0,    2.00000,    0.00000,
  NODE,    4,    0,    0,    3.00000,    1.60000,
  NODE,    5,    0,    1,    4.00000,    0.00000,
END

MATERIAL
  MTRUSS,   1,     210.0e+9,
END

PROPERTY
  PTRUSS,   1,     1,    0.0042000,
END

ELEMENT
  TRUSS,    1,     1,     1,     2,
  TRUSS,    2,     1,     1,     3,
  TRUSS,    3,     1,     2,     3,
  TRUSS,    4,     1,     2,     4,
  TRUSS,    5,     1,     3,     4,
  TRUSS,    6,     1,     3,     5,
  TRUSS,    7,     1,     4,     5,
END

// ***************************************
//  Loadcase definition
// ***************************************
LOADCASE
CASE
  PLOAD,    3,     2,    -240000.0,
END
CASE
  PLOAD,    2,     2,    -240000.0,
END
END

```
`tests` フォルダには、要素タイプ別の入力ファイルの例 (`*.in`) とその計算結果 (`*.out`) が収録されていますので、入力ファイル作成の参考にしてください。

全体的な書式は下記の通りです。
- 空行は無視されます。スペースやタブのみの行も空行と判定されて無視されます。
- 各行の `//` 以降は行末までコメントとして無視されます（行頭が `//` の行は、行全体が空行と同じく無視されます）。
- 任意のラベル名 (上記ではPROPERTY, ELEMENTなど) から始まり、END で終わるブロックに分けられています。ブロックは入れ子にもできます (上記では LOADCASE ブロックに CASE ブロックが入っています)。
- ブロックの中はカードと呼ばれる決まった名前から始まるカンマ区切りのデータ行を定義できます。カードは途中で改行が出来ないため、1行で1つのカードを必ず指定します。文末のカンマは無視されます。
- ブロック名 (END を含む) とカード名は大文字・小文字を区別しません。
- 節点・材料特性・要素特性・要素の ID は 0 以上の整数で指定します。連番である必要はありませんが、同じブロックの中で同じ ID を重複して使うことはできません。

入力ファイルは下記のブロックから構成されます。
- NODE ブロック ... モデルに含まれる節点を定義します。
- MATERIAL ブロック ... モデルに含まれる材料特性を定義します。
- PROPERTY ブロック ... モデルに含まれる要素特性を定義します。
- ELEMENT ブロック ... モデルに含まれる要素を定義します。
- LOADCASE ブロック ... 解析ケース数だけ下記の CASE ブロックを定義します。
  - CASE ブロック ... 個々の解析ケースとして荷重境界条件を定義します。

トップレベルのブロック (NODE ～ LOADCASEまで) は上記に挙げた順序で記述する必要があります。順序が違う場合はプログラムがエラー終了します。LOADCASE ブロックの中の CASE ブロックは与えられた順番に Loadcase #01, #02, ... として計算を行います。前後の CASE に因果関係がないため、入れ替えても計算結果には影響を及ぼしません。

各ブロックにて使用できるカードは次章以降をご参照ください。

なお、本プログラムは多くの有限要素法プログラムと同様、単位系を持ちません。ヤング率・座標・荷重などの入力値は、すべて一貫した単位系で与える必要があります (例: SI単位系なら長さ m、応力 Pa、力 N など)。

## 出力データ概観
PyFLAT は入力したモデルの内容や計算途中の実行内容ログとともに計算結果を標準出力へテキスト形式で出力します。「[入力ファイルの書式](#入力ファイルの書式)」で示したサンプルモデルを実行した場合、2つ目の解析ケース (Loadcase #02) に対して下記のような計算結果出力となります。
```
Post-processing:  ==========================================
Nodal displacement result:  --------------------
     nid          x-disp          y-disp
       1    0.000000e+00    0.000000e+00
       2    2.976190e-04   -7.214866e-04
       3    2.551020e-04   -5.695682e-04
       4    1.275510e-04   -3.113572e-04
       5    3.401361e-04    0.000000e+00

Element stress result:  ------------------------
     eid  ip           str11           str22           str33           str12
       1   1   -5.053918e+07
       2   1    2.678571e+07
       3   1   -1.684639e+07
       4   1   -1.785714e+07
       5   1    1.684639e+07
       6   1    8.928571e+06
       7   1   -1.684639e+07
```
本プログラムの結果出力は下記2つのセクションに掲載されます。
- Nodal displacement result ... モデルに含まれる全節点の変位を出力します。節点ID (`nid`) に対して X, Y 方向変位を出力しています。
- Element stress result ... モデルに含まれる全要素の応力成分を出力します。要素ID (`eid`) の積分点番号 (`ip`) に対する応力成分が出力されています。トラス要素は str11 に軸応力が出力され、str22 以降は空白となります。要素応力は常に全体座標系に対する方向成分で出力されます。

計算結果をファイルへ保存したい場合は、コマンドプロンプトのリダイレクトによりファイルへ保存します。

### エラー終了について
入力ファイルの誤りや計算上の問題が見つかった場合、PyFLAT はメッセージを標準エラー出力に表示し、終了コード 1 で終了します（正常終了時は 0）。

### M2DENG: 平面・軸対称要素用の直交異方性材料特性（工学的定数指定）
2次元平面要素・軸対称のための直交異方性の弾性係数マトリクスを、工学的定数を指定することで計算します。
```
  M2DENG, <label>, <E11>, <E22>, <E33>, <nu12>, <nu13>, <nu23>, <G12>, <angle>
```
- label (int) ... 材料特性ID
- E11, E22, ..., G12 (float) ... 弾性マトリクスの工学的定数
- angle (float) ... 材料のX, Y方向をZ軸周りに回転させる (degree指定)

本カードの係数 `E11, E22, ..., G12` と `M2DORTHO` の係数 `C11, C12, ..., C44` (回転前の弾性係数マトリクスの各成分) との関係を示します。 $\nu_{21}, \nu_{32}, \nu_{31}$ と係数 $\Delta$ を

$$
\begin{aligned}
\nu_{21} = \nu_{12} \frac{E_2}{E_1}, \quad
\nu_{32} = \nu_{23} \frac{E_3}{E_2}, \quad
\nu_{31} = \nu_{13} \frac{E_3}{E_1} \\
\Delta = 1 - \nu_{12}\nu_{21} - \nu_{23}\nu_{32} - \nu_{13}\nu_{31} - 2\nu_{21}\nu_{32}\nu_{13}
\end{aligned}
$$

と計算したとき、弾性マトリクスの各成分は下記の通り計算できます。

$$
\begin{aligned}
C_{11} &= \frac{1 - \nu_{23}\nu_{32}}{\Delta} E_1 \\
C_{22} &= \frac{1 - \nu_{13}\nu_{31}}{\Delta} E_2 \\
C_{33} &= \frac{1 - \nu_{12}\nu_{21}}{\Delta} E_3 \\
C_{12} &= \frac{\nu_{12} + \nu_{32}\nu_{13}}{\Delta} E_2 = \frac{\nu_{21} + \nu_{31}\nu_{23}}{\Delta} E_1 \\
C_{13} &= \frac{\nu_{13} + \nu_{12}\nu_{23}}{\Delta} E_3 = \frac{\nu_{31} + \nu_{21}\nu_{32}}{\Delta} E_1 \\
C_{23} &= \frac{\nu_{23} + \nu_{21}\nu_{13}}{\Delta} E_3 = \frac{\nu_{32} + \nu_{12}\nu_{31}}{\Delta} E_2 \\
C_{44} &= G_{12}
\end{aligned}
$$

この係数 `C11, C12, ..., C44` と回転角 `angle` を `M2DORTHO` に与えて定義した材料特性と、本カードで与えられる材料特性が一致します。


### M2DISO: 平面・軸対称要素用の等方性材料特性
2次元平面要素・軸対称のための材料特性を、等方性材料と仮定して定義します。トラス要素にも使用することができます。
```
  M2DISO, <label>, <young>, <rpois>
```
- label (int) ... 材料特性ID
- young (float) ... 材料のヤング率
- rpois (float) ... 材料のポアソン比

### M2DORTHO: 平面・軸対称要素用の直交異方性材料特性（成分指定）
2次元平面要素・軸対称のための直交異方性の弾性係数マトリクスを、成分を直接指定することで計算します。
```
  M2DORTHO, <label>, <C11>, <C12>, <C22>, <C13>, <C23>, <C33>, <C44>, <angle>
```
- label (int) ... 材料特性ID
- C11, C12, ..., C44 (float) ... 弾性係数マトリクスの成分
- angle (float) ... 材料のX, Y軸方向をZ軸周りに回転させる (degree指定)

`angle=0.0` のときの弾性係数マトリクス $C_0$ は下記の通り表現されます。

$$
C_0 =
\begin{bmatrix}
C_{11} & C_{12} & C_{13} & 0 \\\
C_{12} & C_{22} & C_{23} & 0 \\\
C_{13} & C_{23} & C_{33} & 0 \\\
0 & 0 & 0 & C_{44}
\end{bmatrix}, \qquad
\begin{bmatrix}
\sigma_{11} \\\
\sigma_{22} \\\
\sigma_{33} \\\
\tau_{12}
\end{bmatrix}
= C_0
\begin{bmatrix}
\varepsilon_{11} \\\
\varepsilon_{22} \\\
\varepsilon_{33} \\\
\gamma_{12}
\end{bmatrix}
$$

回転角 `angle` による回転は材料の軸方向を指定の角度だけ回転させることに注意が必要です。回転角をラジアンに直したものを $\theta$ とし、回転後の弾性係数マトリクスを $C(\theta)$ とすると、 $C(\theta)$ は下記の通り計算されます。

$$
C(\theta) = T(-\theta) C_0 \{T(-\theta)\}^T
$$

ただし $T(\alpha)$ はZ軸周りに角度 $\alpha$ だけ弾性係数マトリクスを回転させる変換行列で下記のとおり定義されます。

$$
T(\alpha) = \begin{bmatrix}
\cos^2\alpha & \sin^2\alpha & 0 & 2\sin\alpha\cos\alpha \\
\sin^2\alpha & \cos^2\alpha & 0 & -2\sin\alpha\cos\alpha \\
0 & 0 & 1 & 0 \\
-\sin\alpha\cos\alpha & \sin\alpha\cos\alpha & 0 & \cos^2\alpha - \sin^2\alpha
\end{bmatrix}
$$

これを使った回転 $T(\alpha)C_0\{T(\alpha)\}^T$ は材料に貼り付けられている局所座標系を $\alpha$ だけ回転したものに差し替える処理であり、新しい座標系では材料に固定されたベクトル (例えば主軸方向) は Z 軸周りに $-\alpha$ だけ回転することになります。ここで `angle` は材料に固定されたベクトルを $\theta$ だけ回転する処理なので、 $T(-\theta)$ を作用させています。

## カード仕様: ELEMENT ブロック
<!-- ************************************************************ -->
要素は下記のカード構成となっています。
```
  <card_name>, <label>, <prop_label>, <nid1>, <nid2>, ...
```
- card_name (str) ... 要素カードの名前
- label (int) ... 要素ID
- prop_label (int) ... 要素に紐づける要素特性のID
- nid1, nid2, ... (int) ... 要素の構成節点ID (要素が指定する個数だけ指定)

要素カードとしては2節点のトラス要素 TRUSS と、命名規則 **\<PP\>\<TTTTN\>\<O\>** に沿った各種2次元要素があります。命名規則の各部分の説明は下記の通りです。
- PP ... 対応する解析タイプ (PE:平面ひずみ、PS:平面応力、AX:軸対称)
- TTTTN ... 要素の形状 (TRIA3: 三角形1次要素、QUAD4: 四角形1次要素、TRIA6: 三角形2次要素)。N は節点数を表しています。
- O ... 要素の定式化の種類 (<無印>: 完全積分要素、I: 非適合要素、R: 低減積分要素)

実際に利用できる要素カードの一覧を下記に示します。

| カード名 | 節点数 | 解析タイプ | 形状 | 定式化 |
| :------: | :----: | :--------: | :--: | ------ |
| TRUSS    |  2 | (トラス)   | トラス要素 | |
| PETRIA3  |  3 | 平面ひずみ | 三角形1次 | 完全積分要素 |
| PEQUAD4  |  4 | 平面ひずみ | 四角形1次 | 完全積分要素 |
| PEQUAD4I |  4 | 平面ひずみ | 四角形1次 | 非適合要素 |
| PEQUAD4R |  4 | 平面ひずみ | 四角形1次 | 低減積分要素 |
| PETRIA6  |  6 | 平面ひずみ | 三角形2次 | 完全積分要素 |
| PSTRIA3  |  3 | 平面応力   | 三角形1次 | 完全積分要素 |
| PSQUAD4  |  4 | 平面応力   | 四角形1次 | 完全積分要素 |
| PSQUAD4I |  4 | 平面応力   | 四角形1次 | 非適合要素 |
| PSQUAD4R |  4 | 平面応力   | 四角形1次 | 低減積分要素 |
| PSTRIA6  |  6 | 平面応力   | 三角形2次 | 完全積分要素 |
| AXTRIA3  |  3 | 軸対称     | 三角形1次 | 完全積分要素 |
| AXQUAD4  |  4 | 軸対称     | 四角形1次 | 完全積分要素 |
| AXTRIA6  |  6 | 軸対称     | 三角形2次 | 完全積分要素 |

#### 【補足】要素構成節点の並び順
要素の構成節点は**反時計回り**の順に指定します。時計回りに指定した要素や、つぶれた形状の要素はエラーとなります。

TRIA6 要素は、頂点の節点 nid1 ～ nid3 を反時計回りに指定したあと、nid4 に辺 nid1–nid2 の中間節点、nid5 に辺 nid2–nid3 の中間節点、nid6 に辺 nid3–nid1 の中間節点を指定します。

#### 【補足】低減積分要素の定式化とアワーグラス制御の強さ調整
低減積分要素は γ-Projection 法を使って実装しています。この手法ではアワーグラス制御の強さを「安定化係数」として与えることができますが、その係数はプログラム引数 `--hourglass` で設定できます（詳細は「[アワーグラス制御の強さ (--hourglass)](#アワーグラス制御の強さ---hourglass)」を参照してください）。


#### 【補足】非適合要素の定式化
非適合要素は Wilson-Taylor アルゴリズムを使用しています。

#### 【補足】軸対称要素の座標系
軸対称要素は Y 軸が回転軸となっていますので、座標 $(x, y)$ を円筒座標系の $(r, z)$ に読み変える必要があります。軸対称要素は $x > 0$ の領域に配置してください (回転軸上 $x = 0$ に節点を置くことはできますが、要素が $x < 0$ の領域にかかる場合はエラーとなります)。

次に説明する CASE ブロックの中で指定する軸対称要素への荷重条件は、荷重の種類によって扱いが異なります。
- 集中荷重 (PLOAD) ... その節点が表す円環全周に作用する合計荷重を入力します。
- 要素辺への分布荷重 (ELOAD, EPRESS) ... 単位面積あたりの荷重 (面圧) を入力します。プログラム内で円周長 $2\pi r$ を考慮して積分されます。

#### 【補足】要素構成節点と要素辺の番号の対応
要素カードで指定する節点IDを順番に `nid1`, `nid2`, ... と呼ぶとき、次に説明する CASE ブロックに含まれる要素辺荷重で指定する要素辺番号は下記の対応となります。

- 三角形要素の場合 (1次要素・2次要素共通。2次要素の場合は各辺の中間節点 nid4, nid5, nid6 もそれぞれ要素辺 1, 2, 3 に含まれます)
  - 要素辺 1 → 両端が nid1, nid2 からなる辺
  - 要素辺 2 → 両端が nid2, nid3 からなる辺
  - 要素辺 3 → 両端が nid3, nid1 からなる辺
- 四角形要素の場合
  - 要素辺 1 → 両端が nid1, nid2 からなる辺
  - 要素辺 2 → 両端が nid2, nid3 からなる辺
  - 要素辺 3 → 両端が nid3, nid4 からなる辺
  - 要素辺 4 → 両端が nid4, nid1 からなる辺

## カード仕様: CASE ブロック

### DISP: 変位境界条件
節点に X or Y 方向の強制変位を設定します。
```
  DISP, <node_label>, <dof>, <value>
```
- node_label (int) ... 変位境界条件を設定する節点ID
- dof (int) ... 変位境界条件を設定する方向 (1: X方向、2: Y方向)
- value (float) ... 変位の値

なお、全解析ケースを通して変位ゼロの条件を課す場合は、NODE カードにて直接拘束条件を課したほうが計算的に効率的です。また、NODE カードで拘束した自由度に対して DISP を指定することはできません (エラーとなります)。

### ELOAD: 要素辺への分布荷重条件
要素の辺へ分布荷重を負荷します。
```
  ELOAD, <elem_label>, <edge_id>, <value>, <dir_x>, <dir_y>
```
- elem_label (int) ... 分布荷重を負荷する要素ID
- edge_id (int) ... 要素辺の番号 (1, 2, ...)
- value (float) ... 荷重の値
- dir_x, dir_y (float) ... 荷重の方向

実際に作用する荷重ベクトルは荷重値 `value` に方向を掛け合わせた `(value * dir_x, value * dir_y)` になります。

`value` は単位面積あたりの荷重 (面圧) です。平面ひずみ要素・平面応力要素では要素特性の厚みを掛けて、軸対称要素では円周長 $2\pi r$ を考慮して積分されます。

### EPRESS: 要素辺への分布荷重条件 (圧力)
要素の辺へ圧力荷重を負荷します。ELOADでは設定した任意方向への分布荷重でしたが、EPRESSは要素辺の垂直方向に荷重が負荷されます。
```
  EPRESS, <elem_label>, <edge_id>, <value>
```
- elem_label (int) ... 分布荷重を負荷する要素ID
- edge_id (int) ... 要素辺の番号 (1, 2, ...)
- value (float) ... 荷重の値

`value > 0` の場合に圧縮圧力となり、要素の外から内向きに荷重が作用します。`value` の単位の扱いは ELOAD と同じです。

### PLOAD: 節点への集中荷重条件
節点に X or Y 方向の集中荷重を負荷します。
```
  PLOAD, <node_label>, <dof>, <value>
```
- node_label (int) ... 集中荷重を負荷する節点ID
- dof (int) ... 集中荷重を負荷する方向 (1: X方向、2: Y方向)
- value (float) ... 荷重の値
